# 🚀 Ball Blast Pro

Eine werbefreie Version von Ball Blast, optimiert als PWA (Progressive Web App).

## 📱 Installation

Dieses Spiel muss nicht aus einem App Store heruntergeladen werden. Du kannst es direkt über deinen Browser als App installieren:

### 🍏 Für iOS (iPhone/iPad)
1. Öffne den Link zum Spiel in **Safari**.
2. Tippe unten in der Mitte auf das **Teilen-Symbol** (das Quadrat mit dem Pfeil nach oben).
3. Scrolle nach unten und wähle **"Zum Home-Bildschirm hinzufügen"**.
4. Bestätige mit **"Hinzufügen"**.

### 🤖 Für Android
1. Öffne den Link zum Spiel in **Chrome**.
2. Tippe oben rechts auf die **drei Punkte** (Menü).
3. Wähle **"App installieren"** oder **"Zum Startbildschirm hinzufügen"**.
4. Bestätige die Installation.

---

## 🎮 Bedienung
- **Bewegen**: Wische mit dem Finger über den Bildschirm, um die Kanone zu steuern.
- **Schießen**: Die Kanone feuert automatisch.
- **Upgrades**: Nutze dein gesammeltes Geld im unteren Menü, um den Schaden und die Schussgeschwindigkeit zu erhöhen.

## 🌟 Besonderheiten
- ✅ **Keine Werbung**: Spiel ohne Unterbrechungen.
- ✅ **Offline-fähig**: Einmal installiert, funktioniert die App auch ohne Internet.
- 🤫 **Pro-Tipp**: Es gibt einen versteckten Bereich auf dem Bildschirm, der dir sofort Geld und Diamanten gibt! (Viel Spaß beim Suchen 😉)
